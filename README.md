# 🐢 Desenhos Geométricos com Turtle Graphics em Python

Coleção de scripts visuais que utilizam a biblioteca padrão `turtle` do Python para criar desenhos e explorar geometria computacional de forma interativa.

## 📂 Arquivos no Repositório
- **`turtle_quadrado.py`**: Desenha um quadrado básico de 100x100 pixels.
- **`turtle_retangulo.py`**: Desenha um retângulo de 200x100 pixels.
- **`turtle_quadrado_colorido.py`**: Cria um quadrado estilizado com fundo amarelo claro, caneta azul e espessura grossa.
- **`turtle_formas_geometricas.py`**: Desenha simultaneamente um quadrado e um triângulo multicolorido usando funções modulares.

## 📌 Conceitos Praticados
- Biblioteca nativa `turtle` (`Screen`, `Turtle`, `forward`, `right`, `left`, `done`, `mainloop`).
- Coordenadas e ângulos na tela gráfica.
- Modularização com funções (`def`).

## 🚀 Como Executar

Escolha qualquer um dos scripts para abrir a janela gráfica:
```bash
python turtle_formas_geometricas.py
```
